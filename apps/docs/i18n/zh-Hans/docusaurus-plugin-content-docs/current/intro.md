# express-cargo 简介

## 概览

express-cargo 是一个轻量级中间件库，
面向基于 Express.js 框架的 Web 应用开发。
该库利用装饰器模式，提供基于类的请求数据绑定与验证功能。
它可以将通过 HTTP 请求（Request）收到的多种数据格式自动映射到开发者定义的类，
同时简化这些数据的验证流程。

## 为什么选择 express-cargo？

虽然 Express.js 提供了灵活的架构，
但在处理请求数据时，重复劳动和维护成本很容易成为问题。
express-cargo 正是为了解决这些开发痛点，
从而提升开发效率与代码健壮性。

### 1. 减少样板代码

- **传统方式的挑战**：在 Express.js 环境中，需要在每个路由处理器里反复从 `req.body`、`req.query`、
  `req.params`、`req.headers` 中提取数据，并重复实现类型检查和验证逻辑，这会导致代码重复和生产力下降。
- **express-cargo 的方案**：express-cargo 使用装饰器，在 Request 类中以声明式方式定义数据提取和映射逻辑。
  开发者只需声明数据来源，就能减少重复的数据处理代码，从而提升生产力。

### 2. 增强类型安全与可读性

- **传统方式的挑战**：在 JavaScript 环境中，请求数据的类型可靠性较低；即使在 TypeScript 环境中，手动类型断言也可能带来运行时错误。
  此外，数据处理逻辑和业务逻辑交织在一起，也会降低代码可读性。
- **express-cargo 的方案**：express-cargo 会基于 Request 类中声明的类型执行自动数据映射与类型转换，
  让类型错误更早在编译阶段暴露，并增强运行时稳定性。定义清晰的 DTO 类可以直观呈现 API 期望的输入结构，提高代码可读性。

### 3. 结构化验证与一致的错误处理

- **传统方式的挑战**：当数据验证逻辑分散在多个控制器中时，维护会变得困难，并且难以应用一致的错误处理策略。
- **express-cargo 的方案**：express-cargo 提供内置和自定义验证装饰器，让验证规则可以在 Request 类中声明式定义。
  请求数据绑定过程中会自动执行验证；如果验证失败，可通过用户自定义的错误处理生成一致且可预测的响应。

## ✨ 主要特性

- 基于类的请求绑定
- 内置和自定义验证装饰器
- 支持嵌套对象
- 自动类型转换
- 支持虚拟字段和计算值
- 可自定义错误处理

> 一个轻量级 Express 中间件，使用装饰器实现基于类的请求绑定和验证。

express-cargo 能减少重复任务带来的负担，提高代码质量和稳定性，
让开发者在 Express.js 开发环境中专注于实现核心业务逻辑。
使用 express-cargo，体验更健壮、更高效的 Express.js 应用开发。
